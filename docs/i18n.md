# Languages and the in-app guide

The app is in English (default) and Persian.

## Strings

- UI text lives only in `res/values/strings.xml` and is translated in
  `res/values-fa/strings.xml`, the one file allowed to contain Persian.
- Every new UI string needs both; `StringsTranslationTest` fails when a translation is
  missing, stale, or has different placeholders. Strings that are the same in every language
  (app name, language names, `%d`) are `translatable="false"` and must not be in `values-fa`.
- Use `stringResource` / `pluralStringResource` in composables and `context.getString` /
  `getQuantityString` elsewhere. The activity context carries the chosen language; do not use
  the application context for UI text.
- Errors: never show an exception's message (it is English, for the log). Use
  `context.describe(error)` (`ui/ErrorText.kt`), which maps known error types to strings
  (`err_*`); add a type there when a new error needs its own explanation. Text written for
  the user in code goes in a `UserMessageException`.
- Counts use `<plurals>` (Persian has the same `one`/`other` forms; nouns stay singular).

## Choosing the language

- `AppLanguage` (System, English, Persian) is stored in SharedPreferences `settings`
  (`SettingsRepository.language(context)` reads it before the app singletons exist).
- `MainActivity.attachBaseContext` wraps the context with a configuration that overrides
  **only** the locale, so orientation and other changes still come from the system.
- Changing the language in Settings saves it and calls `recreate()`; Settings stays open.

## Persian layout

- Right to left comes from the locale (`supportsRtl` in the manifest). The player's seek bar
  and centre row (back, play, forward) are forced left to right.
- Fonts: Vazirmatn replaces Atkinson and Archivo in Persian (`Theme.kt`, `typography`), with
  more line height. Subtitle text keeps Atkinson.
- Numbers: film times (`formatTime`, `formatClock`) always use ASCII digits because they are
  typed and parsed in the editor (the time fields are left to right). Other numbers are
  formatted through string resources and appear in Persian digits.
- User content (card text, meanings, subtitles, film names) is never translated. Subtitle
  track languages are named in the app's language (`saving-lines.md`).

## In-app guide

- `ui/GuideScreen.kt`: an introduction and ten sections that open on tap (getting started,
  subtitles, player controls, saving a line, cards and review, role-play, backup, settings,
  tips, troubleshooting). The text is in the strings (`guide_*`).
- Opened from the "?" icon on Home and from Settings. A welcome card on Home points to it
  until closed (`SettingsRepository.welcomeDismissed`).
- **When a feature changes, update its guide section in both languages.**
